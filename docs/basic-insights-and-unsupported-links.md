# Basic Insights and unsupported feature links (#281/#282)

Draft only: no merge or deployment is part of this change.

Chess Insights reuses Lichess's on-demand human indexing, native eligible rated-game selection, Mongo aggregation, charts, filters, game samples and sharing preferences. The focused site starts with game results by time control. It exposes results, rating gain and average opponent rating, grouped by date, time control, colour, opening family/variation or result, with native date-period filters. Historical correspondence data remains historical analytics; no correspondence game creation is enabled. Opening names remain native proper names. Chosen names are labels; canonical account IDs remain in all links and stored data.

Accuracy, ACPL, tactical-awareness and other engine-dependent queries are excluded from both the selectors and the request boundary. Browser reviews are not uploaded to the native AnalysisRepo by this change. Existing native rating-stability requirements and missing/empty data semantics remain. Generation/refresh is owner-only on the focused site; native sharing still controls chart reads. There is no bot-roster backfill, background indexing, inference service, rating change or new data model. The two native Insights indexes are declared in the existing guarded database-index script; applying them is a later deployment operation.

Known unsupported feature links show a native translated “This functionality is not yet supported.” page with status 501. The browser retains the original URL and ordinary Back navigation. The gateway forwards only the fixed `/club/unsupported` path, discarding the original query; it never forwards the blocked feature controller. Write methods remain rejected. Unknown paths retain 404, and native missing users/games and access checks retain their normal behavior.

Audited destinations include blog creation, community/month/topic/by-Lichess/liked/friend feeds, personal blogs/drafts/feeds, and inherited navigation to coaches, tournaments, simuls, teams, broadcasts/TV, Puzzle Racer, Tutor, videos/streamers/mobile, removed public importing, unsupported player categories and forum/study/game search. The same known feature prefixes cover their child links. This is a small product routing list, not a crawler or routing framework. Supported destinations and intentional external Lichess credits are retained. No disabled feature is enabled by its notice page.

All newly exposed Insights controls, descriptions, preset names, chart/series labels, filter feedback, privacy/refresh text, empty/error states, the profile card and the unsupported notice use existing native catalogs in all ten supported languages. Native identities, privacy checks and analysis semantics remain authoritative. Rebase checks must keep the focused API allowlist, UI choices and translations aligned, and retain native result-series Win/Draw/Loss order for chart colors.
