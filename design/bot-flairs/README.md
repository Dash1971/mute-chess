# Mute Chess bot flairs

Original raster artwork generated with Codex’s built-in image-generation tool on 2 November 2026, at the owner’s request for cyberpunk profile flairs. Released as part of this AGPL-3.0-only project. Existing Lichess flairs retain their upstream attribution and licensing.

The six original transparent PNGs are in `originals/`. `manifest.json` records original SHA-256 values and the native IDs. The native patch contains lossless 60×60 WebP derivatives; only resizing/format conversion was applied, preserving transparency. Native flair selection, validation and display are retained. The **Bot flairs** category is available to human profiles as well as assigned bots.

## Prompt set (built-in mode)

Shared prompt: “Use case: stylized-concept. Asset type: one profile flair icon for Mute Chess, displayed beside usernames at only 24–32 pixels. Style: polished bold cyberpunk game UI emblem, flat graphic shapes with very restrained cel shading, graphite/chalk/mint with one violet accent, strong filled silhouette and thick readable edges, minimal interior detail. Composition: a SINGLE isolated centered icon, square canvas, roughly 75 percent of frame, generous transparent padding. Genuine transparent background. Readable on dark AND light UI. No text, no letters, no numerals, no watermark, no surrounding badge, no frame, no gradients fading into background, no scene. Render the emblem as original finished raster artwork, NOT an icon sheet.”

Subjects supplied separately, one generation per asset:

- Circuit Knight: “A bold angular chess knight head whose neck becomes three chunky circuit traces, one small luminous node.”
- Synthetic Eye: “A single stylized synthetic eye: angular eyelids, bright mint iris, two short circuit terminals. Distinctive cyberpunk emblem.”
- Neural Chip: “A dark angular neural processor chip with four large contacts on each side and a luminous mint branching neuron inside.”
- Neon Fox: “An angular cybernetic fox head, pointed ears, sharp mint cheek plates, one small violet eye. Strong silhouette.”
- Origami Crane: “A folded origami crane made of graphite panels with bright mint fold edges and one subtle violet accent. Clean readable silhouette.”
- Ghost Terminal: “A small mischievous digital ghost with angular lower edge, two bright eyes and a simple mint terminal cursor emblem. Distinct cyberpunk silhouette.”
